# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's **private vulnerability reporting**:

1. Go to the [Security tab](https://github.com/binkybell225/BluEmpress/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe what you found and how to reproduce it. Only the owner can see your report.

You can report problems with the app, the tester signup process, this repository, or any exposed information (for example, something private that was published by mistake).

## What to expect

This is a small beta run by one person, so there is no guaranteed response time. We will read every report, and we will tell you if we need more detail. Please give us reasonable time to fix a problem before telling others.

## Please don't

- Access, change, or delete other people's data.
- Run automated attacks or load tests against the app or its servers.
- Include real secrets or private data in your report beyond what is needed to show the issue.

## Supported versions

Only the current closed-test build on Google Play is supported.

There is no bug bounty and no payment is offered for reports.
