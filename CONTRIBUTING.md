# Contributing to BluEmpress 👑

Thank you for wanting to help! This is a **public beta** of an Android app. The app itself is closed (all rights reserved), so the way to contribute is through **suggestions**, mostly to the public JSON data in [`/data`](data).

## What you can contribute

- **Issues**: bug reports, feedback, ideas, and tester signup help (use the templates).
- **Pull requests that change only `/data`**: fix a typo, suggest a new mood vibe, a new classy BluRoom Check line, a clearer FAQ answer, or a roadmap idea.
- **Discussions**: share ideas, say hi, and help other testers.

## What we cannot accept

- Pull requests that touch anything outside `/data` (workflows, scripts, community files, images, the landing page). Please open an issue instead.
- App code, keys, tokens, passwords, emails, phone numbers, or anyone's private information.
- Content that uses slurs, cursing, harassment, real private people, or copyrighted material you do not own.
- AI-generated bulk changes with no human review.

## How it works

1. Fork the repository and make a branch.
2. Change only files in `/data`. Keep the JSON valid. The checks run automatically and use read-only permissions.
3. Open a pull request using the template and tick every box.
4. The owner reviews every pull request. **Nothing is merged without owner review, and there is no guarantee that any suggestion will be merged**, even a good one.

`main` is protected: nobody except the owner can change it.
