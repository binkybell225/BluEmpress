# Getting help

| I want to… | Go here |
|---|---|
| Join the closed test | Follow the 3 steps in the [README](README.md#-join-the-closed-test) |
| Sign-up or opt-in is not working | Open a [Tester signup help issue](https://github.com/binkybell225/BluEmpress/issues/new/choose) (never post your email publicly) |
| Report a bug | Open a [Bug report](https://github.com/binkybell225/BluEmpress/issues/new/choose) |
| Share feedback or a review | Open a [Feedback issue](https://github.com/binkybell225/BluEmpress/issues/new/choose) |
| Suggest a change to the JSON data | Open a [JSON improvement idea](https://github.com/binkybell225/BluEmpress/issues/new/choose) or a pull request to `/data` |
| Ask a question or chat | [Discussions](https://github.com/binkybell225/BluEmpress/discussions) |
| Report a security problem | [SECURITY.md](SECURITY.md) (private) |
| Ask to delete your tester data | See [PRIVACY.md](PRIVACY.md) |

This is a one-person beta. Replies can take a few days, and there is no guaranteed response time.
